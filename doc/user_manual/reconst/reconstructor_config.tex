\subsection{Common}

\subsubsection{Main}

\begin{figure}[H]
    \center
      \includegraphics[width=16cm,frame]{figures/dialog_main.png}
    \caption{Calculate References Main}
\end{figure}

In the main tab, the following parameters can be set:

\begin{itemize}
\item Data Source: Data source to be created for calculated references
    \begin{itemize}
    \item Name, SAC, SIC: Data source parameters
    \item Line ID: Line ID to be used
    \end{itemize}
\item Data Timeframe: Time window of data to be processed
    \begin{itemize}
    \item Begin / End timestamps
    \end{itemize}
\item Data Slicing: Time slice sizes
    \begin{itemize}
    \item Slice Length: Duration of a time slice
    \item Slice Overlap Length: Duration of an overlap region to "glue" slices together
    \end{itemize}
\item Delete All Calculated Reference Trajectories: If active, all previous calculated references are deleted
\item Skip Writing of Reference Trajectories: If active, calculated references and associations are not written into the database
\end{itemize}
\ \\

\subsubsection{Data Sources}

\begin{figure}[H]
    \center
      \includegraphics[width=16cm,frame]{figures/dialog_data_sources.png}
    \caption{Calculate References Data Sources}
\end{figure}

In this tab, the data sources that contribute to the calculated references can be selected. \\

Please \textbf{note} that deselected data sources are still associated, but their target report positions do not contribute to the references. \\

Please also \textbf{note} that for ground surveillance datasets containing \textbf{SMRs}, it is imperative to set the detection type to "Primary Only" as well as to enable the "Ground Only" checkbox. Otherwise, SMR plots will be associated over long distances and cause sub-optimal reconstructor results.

\subsubsection{Classification}

In the classification tab, special parameters can be set to identify the AnyAircraft and Vehicle categories. Any target (without any other class information) and any Mode C code above the given 'Minimum Aircraft Altitude' will be classified as AnyAircraft. Vehicles (without any other class information) can be set by giving a list of Mode S Aircraft Identification and/or Aircraft Addresses. \\

\subsubsection{Reference Calculation}
\label{sec:reconst_scorum_ref_calc} 

\begin{figure}[H]
    \center
      \includegraphics[width=16cm,frame]{figures/dialog_ref_calc.png}
    \caption{Reference Calculation parameters}
\end{figure}

In this tab, the reference calculation parameters can be set, i.e. the Kalman and reconstruction parameters used for position estimation of the references. \\

\begin{table}[H]
    \centering
    \footnotesize
    \hspace*{-1.5cm}
    \begin{tabular}{|p{4.5cm}|p{6.5cm}|l|l|l|}
    \hline
    \textbf{Parameter Name} & \textbf{Description} & \textbf{Complexity} & \textbf{Default} & \textbf{Range} \\ \hline
    Process Stddev (Ground) & Assumed process noise standard deviation for targets on ground (affects maneuverability allowance). & Basic & 3.0 m & $>0$ m \\ \hline
    Process Stddev (Air) & Assumed process noise standard deviation for airborne targets. & Basic & 7.0 m & $>0$ m \\ \hline
    Process Stddev (Unknown) & Assumed process noise standard deviation for targets with unknown state. & Basic & 5.0 m & $>0$ m \\ \hline
    Maximum Time Step (Ground) & Maximum time interval between updates used for interpolation/prediction on ground. & Intermediate & 5.0 s & $>1$ s \\ \hline
    Maximum Time Step (Air) & Maximum time interval between updates used for interpolation/prediction in air. & Intermediate & 10.0 s & $>1$ s \\ \hline
    Resample Interval & Time interval for the output trajectory (if resampling enabled internally). & Basic & 1.0 s & 0.1 -- 30 s \\ \hline
    Resample Process Stddev (Ground) & Process noise applied specifically during the resampling phase for ground targets. & Advanced & 2.0 m & $>0$ m \\ \hline
    Resample Process Stddev (Air) & Process noise applied specifically during the resampling phase for airborne targets. & Advanced & 5.0 m & $>0$ m \\ \hline
    Resample Process Stddev (Unknown) & Process noise applied during resampling for unknown state targets. & Advanced & 3.0 m & $>0$ m \\ \hline
    Filter Result References & Enable filtering of the final reference trajectory based on estimated accuracy (Standard Deviation). & Intermediate & True & True/False \\ \hline
    Max. Stddev & Maximum allowed position standard deviation for a point to be included in the final reference. & Intermediate & 100.0 m & $>0$ m \\ \hline
    \end{tabular}
    \caption{Reference Calculation parameters}
    \label{tab:reconst_params}
\end{table}

Result resampling is enabled in order to obtain reference trajectories with a homogeneous sample rate. 
It is carried out by interpolating the Kalman states at fixed time-steps. The accuracy of the resulting samples
follows the Kalman accuracies more closely when interpolating near the endpoints of a segment, and it will decrease
in the middle of a segment. The amount of decrease of accuracy will depend on the time duration of the segment and the used 
process standard deviation (parameter \textit{Resample Process Stddev}).

\paragraph{Parameter Usage}

Association of target reports to UTNs:
\begin{itemize}
\item Maximum Comparison Time Difference: Maximum time difference for Mode A/C comparisons
\item Maximum Track Time Difference: Maximum time difference to re-use previous system track to UTN associations
\item Maximum Acceptable Distance (Ground/Air): Maximum distances for allowed associations
\item Maximum Altitude Difference: Maximum Mode C difference for allowed associations
\end{itemize}
\ \\

Self-associate new targets (find matching UTNs created by the same target):
\begin{itemize}
\item Maximum Comparison Time Difference: Maximum time difference for Mode A/C comparisons
\item Maximum Distance (Ground/Air)
\begin{itemize}
\item Acceptable/Dubious/Erroneous: Each type of distance is counted
\item If too many Erroneous (5-10\%): Not associated
\item If too many Dubious (30-50\%): Not associated
\item If Acceptable: Consider as match
\item Association of targets is made for best matches fulfilling an average position difference score
\end{itemize}
\item Minimum Updates: Minimum number of updates needed to consider a match
\item Minimum Time Overlap Probability: Minimum time overlap probability for at least one of the targets to consider a match
\end{itemize}

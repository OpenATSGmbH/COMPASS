\section{Configuration Dialog}
\label{sec:analyze_dialog}

Selecting an entry from the 'Analyze' menu opens the Analyze Data Source dialog, pre-configured for MLAT. \\\\

\begin{figure}[H]
  \centering
  \hspace*{-2.4cm}
    \includegraphics[width=18.8cm,frame]{figures/analyze_mlat.png}
  \caption{Analyze MLAT dialog}
\end{figure}


The dialog is split into a navigation tree on the left and a stacked detail widget on the right. \\

\begin{itemize}
\item Left tree
\begin{itemize}
\item 'Data Source' node: top-level entry; selecting it shows the Data Source selection widget on the right
\item One node per available inspector, each with an active checkbox controlling whether that inspector runs
\end{itemize}
\item Right pane
\begin{itemize}
\item Shows the settings widget of the currently highlighted tree node
\item When the 'Data Source' node is selected, lists all Data Sources of the bound DSType with checkboxes
\item When an inspector node is selected, exposes the parameters specific to that inspector
\end{itemize}
\item Bottom
\begin{itemize}
\item 'Run' button: executes the enabled inspectors; performs validation first
\item 'Cancel' button: closes the dialog without running
\end{itemize}
\end{itemize}
\ \\

Inspectors whose prerequisites are not met (e.g. Pro inspectors without an active Professional license, or RU-based inspectors without CAT020 data) appear greyed out. The corresponding tooltip explains the reason the inspector cannot be selected. \\

\subsection{Scope Filter}
\label{sec:analyze_scope_filter}

The 'Scope Filter' box on the 'Data Source' page restricts which target reports are used by the analysis.
It is applied when the data is loaded, so all inspectors use the same target reports. All selected constraints must be met. \\

\begin{figure}[H]
  \center
  \hspace*{-2.4cm}
    \includegraphics[width=18.8cm,frame]{figures/analyze_mlat_scope_filter.png}
  \caption{Analyze dialog Scope Filter}
\end{figure}

\begin{itemize}
\item Use Ground Only: keeps only target reports on the ground
\begin{itemize}
\item On the ground: ground bit set, or ground-only target type, or ground-only Data Source (SMR)
\end{itemize}
\item Minimum Flight Level: keeps only target reports at or above the given flight level
\item Maximum Flight Level: keeps only target reports at or below the given flight level
\begin{itemize}
\item Both use the barometric altitude, target reports without an altitude are kept
\end{itemize}
\item Use Evaluation Exclusions: leaves out the data excluded in the Evaluation
\begin{itemize}
\item Targets not used in the Evaluation, with their reference and test target reports
\item Target reports in the excluded time windows of a target
\item If the Evaluation timestamp filter is used: target reports outside the timestamp begin and end, and in the global excluded time windows
\item Target reports without a target (unassociated) are only checked against the global time constraints
\item A reference period ends at an excluded time window and starts again after it, as in the Evaluation
\item Excluded requirements are only used by the Evaluation and are ignored
\end{itemize}
\item Limit by Sectors: keeps only target reports inside at least one of the selected sector layers
\begin{itemize}
\item Same inside test as the Evaluation, including the altitude limits and exclusion sectors
\item 'Run' is disabled when no sector layer is selected
\end{itemize}
\end{itemize}
\ \\

The Evaluation exclusions are defined in the \nameref{sec:targets} tool of the Flight Deck:

\begin{itemize}
\item Use flags: \nameref{sec:ui_eval_usage}, also with the \nameref{sec:ui_target_filtering} dialog, e.g. to leave out certain target types
\item Global time constraints: \nameref{sec:ui_eval_global_excl_tw}
\item Target time windows: \nameref{sec:ui_eval_target_excl_tw}
\end{itemize}
\ \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} \textbf{Please note that the exclusions are read when the analysis is run.
If they are changed later, the analysis report has to be updated to use the changed exclusions.} \\

\subsection{Report Figures}
\label{sec:analyze_report_figures}

The 'Report Figures' group on the 'Report' page sets how the figures of the analysis report are drawn (see \nameref{sec:report_section_figures}):

\begin{itemize}
\item Histogram Log Scale: Logarithmic count axis of the histograms with one data series, on by default
\begin{itemize}
\item Histograms with several data series are stacked and always use a linear axis
\end{itemize}
\item Export Image Width, Export Image Height: Layout size of an exported figure image, 1200 x 800 by default
\begin{itemize}
\item The image has twice this size in pixels
\item A smaller layout gives larger text in the image, e.g. for two figures next to each other on one page
\end{itemize}
\item Report Figure Background: See below
\end{itemize}
\ \\

The number of histogram bars of the update interval histograms is set in the ADS-B and MLAT Sensor Coverage settings ('Histogram Bins', 10 by default). \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} \textbf{Please note that these settings are written into the figures when the analysis runs.
Changed settings apply to the next analysis, not to existing reports.} \\

\subsection{Report Figure Background}
\label{sec:analyze_report_figure_background}

The 'Report Figure Background' group in the 'Report Figures' group on the 'Report' page sets the background of the report figures with a grid over longitude and latitude (e.g. the coverage figures).
The report shows and exports these figures with this background, and the 'View' button gives it to the Grid View.
The values are the same as the background items of the Grid View, see \nameref{sec:grid_background}. \\

\begin{figure}[H]
  \center
  \hspace*{-2.4cm}
    \includegraphics[width=18.8cm,frame]{figures/analyze_report_figure_background.png}
  \caption{Analyze dialog Report Figure Background}
\end{figure}

\begin{itemize}
\item Background Color: Color below the map and the grid, black by default. 'Select Color' opens the color dialog.
\item Show Map: Draws the map below the grid, off by default
\begin{itemize}
\item Map tiles that are not in the cache need an internet connection
\end{itemize}
\item Map: Map file of the maps folder, the first map file by default
\item Map Opacity: Opacity of the map in percent, 50\% by default
\item Show National Borders: Draws the national borders above the grid, on by default
\item Show Sectors: Draws the selected sectors above the grid, on by default
\item Sectors: One checkbox per sector layer and per sector of the active Data Context
\begin{itemize}
\item By default, no sector layer is selected
\item 'Select All' selects all sector layers and all sectors, 'Select None' deselects all sector layers
\item After a change, the selection is stored. A sector layer that is added to the Data Context later is selected.
\end{itemize}
\end{itemize}
\ \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} \textbf{Please note that the background is written into the figures when the analysis runs.
A changed background applies to the next analysis, not to existing reports.} \\

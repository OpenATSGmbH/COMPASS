\subsection{Position Accuracy [Pro]}

Requires a Professional license. Three views, each rendered as the three standard projections:

\begin{itemize}
\item Reported Position Accuracy: position-accuracy reported by the MLAT source
\item Horizontal Position Offset: offset of MLAT positions vs. RefTraj
\item Reported Accuracy Consistency: ratio reported / observed (ideal 1.0)
\end{itemize}
\ \\

For CAT020 sources providing both I020/500 and a REF Position Accuracy item, the reported views are rendered once per source. \\

\subsection{RU Effect [Pro]}

Requires a Professional license and at least one CAT020 source with contributing-receiver information. Quantifies per-RU contribution to MLAT accuracy:

\begin{itemize}
\item Marginal effect table: per-RU error statistics with vs. without that RU
\item Redundancy curve: error vs. number of contributing RUs
\item Per-RU drill-down: dual histogram plus per-cell error heatmap for the selected RU
\end{itemize}
\ \\

No per-inspector settings; uses the shared grid resolution and data source selection. \\

\section{Prerequisites}
\label{sec:analyze_prereqs}

Before the task can be run, the following preconditions must be satisfied: \\

\begin{itemize}
\item MLAT data (CAT010 or CAT020) must exist
\item Calculated Reference Trajectories must exist, see \nameref{sec:reconst}
\item For the Pro inspectors (Position Accuracy, RU Coverage, RU Effect), a valid Professional license must be active
\item The 'RU Coverage' and 'RU Effect' inspectors additionally require CAT020 with contributing-receiver information. They are greyed out otherwise.
\end{itemize}
\ \\

Sectors defined in the active Data Context (see \nameref{sec:configure_data_context}) not used in calculation but display sector boundaries on the resulting maps. \\

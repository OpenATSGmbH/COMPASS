\section{Configuration Upgrade}

If the used version of COMPASS has never been run on the workstation, the configuration (and additional application data) will be copied into a subfolder of the home directory (e.g. \textasciitilde/.compass/0.9.0/). \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} When switching from an older COMPASS version to a newer one, it is no longer required to re-import data sources. But previously saved View presets or added custom DB filters will have to be re-created. \\

For more details about the configuration, please refer to section \nameref{sec:appendix_configuration}.

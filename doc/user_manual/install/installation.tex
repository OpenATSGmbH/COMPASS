\chapter{Installation}
\label{sec:installation}

COMPASS is available as a binary package for two 64-bit operating systems. Both packages contain the same features, including the Geographic View, and require no installation:

\begin{itemize}
\item Linux: AppImage, see \nameref{sec:install_appimage}
\item Windows: zip package, see \nameref{sec:install_windows}
\end{itemize}
\ \\

Both packages can be downloaded from \url{https://github.com/hpuhr/COMPASS/releases}. \\

COMPASS can also be built from source. A source build does not include the Geographic View and other closed-source features, but allows development of additional features. The recommended option for non-developers is the binary package. \\

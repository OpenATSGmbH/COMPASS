\chapter{Installation}
\label{sec:installation}

COMPASS can either be built from source (which does not include the Geographic View, but allows development of additional features), or downloaded as a binary distributable which includes the Geographic View:

\begin{itemize}
\item Linux: \textit{AppImage}
\item Windows: zip package
\end{itemize}
\ \\

The recommended option for non-developers is the binary distributable. \\

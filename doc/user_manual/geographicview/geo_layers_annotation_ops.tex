\subsubsection{Annotation Operations}
\label{sec:geo_annotation_ops}  

Annotations are listed in the 'Annotations' node of the 'Layers' tab. \\

There are two kinds of annotations listed under this node.

\paragraph*{View Point} Annotations provided by an active View Point, e.g. selected evaluation results or externally provided annotation data.
See \nameref{sec:key_concepts_viewpoints} for an introductory explanation about View Points. \\

View Point annotations persist as long as the providing View Point is active. \\

A RMB click on the 'View Point' node opens a context menu containing the following operations:

\begin{table}[H]
    \center
    \begin{tabular}{ | l | l |}
      \hline
      \textbf{Operation} & \textbf{Description} \\ \hline
      Show & Shows all annotations of a selected name \\ \hline
      Hide & Hides all annotations of a selected name \\ \hline
      Remove All & Removes the View Point annotations from the view \\ \hline
    \end{tabular}
\end{table}

The 'Show' and 'Hide' submenus list only annotation names that exist more than once. 'Remove All' is only listed if View Point annotations exist, and removes them in this Geographic View only. \\

A RMB click on a View Point annotation that contains a grid (e.g. an evaluation or Data Source Analysis figure) opens a context menu containing the following operation:

\begin{table}[H]
    \center
    \begin{tabular}{ | l | l |}
      \hline
      \textbf{Operation} & \textbf{Description} \\ \hline
      Edit Coloring & Changes the colors of the grid, see \nameref{sec:geo_grid_coloring} \\ \hline
    \end{tabular}
\end{table}

\paragraph*{Grids} Grid data imported into Geographic View. Grid data can be imported into
Geographic View either by sending it from a Grid View (see \nameref{sec:grid_export_geographic}), or as an external GeoTIFF file (see \nameref{sec:geo_geotiff_import}). \\

A grid sent from a Grid View contains its cell values, so its colors can be changed. A GeoTIFF file is imported as an image, so its colors cannot be changed. \\

Imported grid items persist in a Geographic View until COMPASS is closed. \\

A RMB click on the 'Grids' node opens a context menu containing the following operations:

\begin{table}[H]
    \center
    \begin{tabular}{ | l | l |}
      \hline
      \textbf{Operation} & \textbf{Description} \\ \hline
      Remove All & Removes all imported grids from the view \\ \hline
    \end{tabular}
\end{table}

A RMB click on an imported grid item opens a context menu containing the following operations:

\begin{table}[H]
    \center
    \begin{tabular}{ | l | l |}
      \hline
      \textbf{Operation} & \textbf{Description} \\ \hline
      Zoom to Item & Zooms to the grid item \\ \hline
      Rename & Renames the grid item to a specified name \\ \hline
      Export & Exports the grid item to a GeoTIFF file \\ \hline
      Opacity & Sets the opacity of a grid item \\ \hline
      Edit Coloring & Changes the colors of the grid, see \nameref{sec:geo_grid_coloring} \\ \hline
      Remove & Removes the grid item from the view \\ \hline
    \end{tabular}
\end{table}

'Edit Coloring' is only listed for grids sent from a Grid View, not for GeoTIFF imports. \\

\paragraph*{Edit Coloring}
\label{sec:geo_grid_coloring}

'Edit Coloring' opens the 'Grid Coloring' dialog, which changes the colors of a grid in this Geographic View. The dialog contains the following settings:

\begin{itemize}
 \item Color Scale: Colors used for the cell values
 \item Color Steps: Number of colors taken from the color scale
 \item Logarithmic Scale: Maps the values to the colors on a logarithmic scale
 \item Minimum Value: Value shown with the first color
 \item Maximum Value: Value shown with the last color
\end{itemize}

If both 'Minimum Value' and 'Maximum Value' are empty, the value range of the grid data is used. \\

The dialog has the following buttons:

\begin{itemize}
 \item Cancel: Closes the dialog without changes
 \item Reset: Restores the coloring stored with the grid
 \item OK: Shows the grid with the set coloring
\end{itemize}

The legend in the 'Layers' tab and the legends in exported images show the changed colors and values. \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} \textbf{Please note that:}
\begin{itemize}
 \item The changed coloring of a View Point grid applies only while the View Point is active. The View Point and the report figure keep the stored coloring.
 \item 'Edit Coloring' is disabled for grids with named categories (e.g. 'Dominant RU'), since their colors identify the categories.
 \item For grids with two colors (e.g. passed and failed cells), only the color scale can be changed.
\end{itemize}

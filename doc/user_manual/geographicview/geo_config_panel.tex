\section{Configuration Panel}
\label{sec:geoview_config_panel}

\begin{figure}[H]
    \centering
    \includegraphics[width=8cm,frame]{figures/geoview_config_panel.png}
  \caption{Geographic View configuration panel}
\end{figure}

There exist 5 tabs:
\begin{itemize}
 \item Layers: Allows configuration of what data is shown, and access to the map and measurement functions
 \item Style: Allows configuration of how data is shown
 \item Labels: Allows configuration of how data is labeled
  \item Others: Allows configuration of the height usage in the shown data
\end{itemize}

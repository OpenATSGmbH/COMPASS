\section{Appendix: Evaluation Standards}
\label{sec:appendix_eval_standards}

In this section, the supplied standard definitions are documented, listing which requirement of the source document is mapped onto which COMPASS requirement, and how. \\

The standard documents themselves are protected by copyright and are not reproduced here. Only the section and requirement identifiers of the source documents are given, so that a reader holding the document can follow the mapping. The documents can be obtained from EUROCAE, see the links in the \nameref{sec:eval_config} section of the \nameref{sec:eval} chapter. \\

The following applies to all supplied standards:
\begin{itemize}
\item A standard is a pure configuration, stored in the Configuration, see \nameref{sec:appendix_configuration}. It can be copied and adapted in the 'Standard' tab, without a change to the application.
\item The supplied values are the ones the author derived from the source document. They are a starting point, not a certification. The user remains responsible for checking the mapping against the applicable edition of the document.
\item Requirements addressing interrogation behavior, capacity, start-up, switchover, failure reporting, environment and power cannot be assessed from recorded surveillance data, and are therefore not part of the supplied definitions.
\item A requirement group has to be assigned to the sector layer it applies to, in the 'Main' tab of the Evaluation dialog. Without this assignment no requirement of the group is evaluated.
\end{itemize}

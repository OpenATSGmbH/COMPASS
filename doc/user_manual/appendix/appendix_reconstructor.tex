Primary Only Mode has the following options:
\begin{itemize}
    \item \textbf{Probabilistic Scoring}: Primary plots are associated to existing targets using probabilistic distance measures at the end of a calculation pass. Tentative target creation will be disabled.
    \item \textbf{JPDA + Probabilistic Scoring}: Primary plots are associated using JPDA. JPDA may associate them to existing targets or initiate new tentative targets with them, otherwise they will be re-associated to existing targets using probabilistic distance measures at the end of a calculation pass.
\end{itemize}
\ \\

Please \textbf{note} that:
\begin{itemize}
\item All of the features above \textit{should} work as intended with the given default values
\item Should this not be the case, disabling of certain features can be a valid workaround until the issue was resolved by a bugfix
\item Use Risky ADS-B: This feature will allow usage of MOPS V0 and V1 transponders, as well as position data with unknown accuracy
\begin{itemize}
\item While accuracy determination algorithms will automatically determine usage of such "risky" ADS-B data, absolute correctness can not be guaranteed in all situations
\item Usage of this feature is therefore disabled by default, and activation should always be accompanied with manual verification of the reconstruction results
\end{itemize}
\item Do Full Primary-Only Tracking: This will commonly increase computional requirements by factor 3-5. Can be disabled for large datasets or slower workstations, at cost of primary-only reconstruction quality.
\end{itemize}

The given minimum/maximum standard deviations are required to combat the position accuracy estimation spiraling into edge cases in high clutter scenarios. Basically, estimated accuracies are bound to the given range values, to mitigate non-association due to too small standard deviations or associate-all due to too high standard deviations.

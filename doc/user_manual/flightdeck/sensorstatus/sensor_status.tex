\section{Sensor Status}
\label{sec:sensor_status}

In the \textit{Sensor Status} Flight Deck tool, Data Sources existing in live data are listed,
together with their current CAT063 sensor status, if available. \\

\textbf{Note} that this tool is only available in Live Mode. \\

For a more detailed explanation, refer to section \nameref{sec:sensor_status_live_mode}.

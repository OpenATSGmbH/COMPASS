\subsection{Calculate Radar Plot Positions}
\label{sec:ui_proc_radar_plot_pos}

This dialog allows (re-)calculation of Radar plot latitude/longitude position information based on the defined data sources and fixed field transponders (FFTs).

\begin{figure}[H]
  \centering
    \includegraphics[width=7cm]{figures/proc_calc_radar.png}
  \caption{Calculate Radar Plot positions}
\end{figure}

Please note that for this step the Radar data source positions have to be set in the database (see \nameref{sec:ui_configure_data_sources}), otherwise no plot position can be calculated.  \\

There is currently only one projection method (radar polar coordinates to WGS-84 coordinates), called \textit{RS2G}, available. 

\paragraph{RS2G Projection}

For this projection, no additional attributes must be given. Please \textbf{note} that this projection is based on a common 'radar slant to geodesic transformation', it should be equivalent to the ARTAS projection. 

\paragraph{FFTs}

The altitude of Radar plots is commonly derived from the Mode C code, and used in the slant range correction. In FFTs, the downlinked Mode C code is a configured value, often very dissimilar to the real altitude, therefore causing position errors. \\

To mitigate this unwanted behavior, if the FFTs are correctly set in the respective configuration (see \nameref{sec:ui_configure_ffts}), plots generated by FFTs are identified and the FFT altitude is used for the slant range correction. \\

A plot matches an FFT if at least one secondary identification value exists in both the plot and the FFT and is equal. A value that exists in both and differs prevents the match. The following criteria are used:

\begin{itemize}
\item Mode S Address (hexadecimal): Identifies the FFT. Not used for CAT001, which carries no aircraft address
\item Mode 3/A Code (octal): Identifies the FFT
\item Mode C Code [ft]: Confirms a match only. It can prevent a match, but it can never establish one
\item Latitude, Longitude: WGS-84 position in degrees. The plot-FFT distance must be lower than 5000 m
\end{itemize}
\ \\

\includegraphics[width=0.5cm]{../../data/icons/hint.png} \textbf{Please note that} the position alone never identifies an FFT, because aircraft can overfly the FFT position. Primary-only plots are therefore never matched. \\

The Mode 3/A Code 7777 is always treated as an FFT, without any further check. \\

The Altitude [ft] of the matched FFT is the value used for the slant range correction. \\

\paragraph{Usage}

Using the 'OK' button the task can be performed. During import a status indication will be shown:

\begin{figure}[H]
  \centering
    \includegraphics[width=6cm]{figures/proc_calc_radar_done.png}
  \caption{Calculate Radar Plot positions done}
\end{figure}

Please \textbf{note} that this task can be re-run with different projections if wanted.

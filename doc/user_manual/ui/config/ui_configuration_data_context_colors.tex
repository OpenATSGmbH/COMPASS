\subsubsection{Colors}
\label{sec:configure_data_context_colors}

The 'Colors' leaf in the tree opens the color palettes used by the active Data Context. \\

\begin{figure}[H]
  \center
    \fbox{\parbox{0.8\textwidth}{\vspace{1.5cm}\centering \textcolor{red}{\textbf{[FIGURE TODO: Colors widget showing the Light/Dark preference, DSType palette, DBContent palette and per-data-source color controls]}}\vspace{1.5cm}}}
  \caption{Data Context: Colors widget}
\end{figure}

The widget configures the palettes consumed by Color Mode (see \nameref{sec:color_mode}) and offers the following controls:

\begin{itemize}
\item Preference: Light / Dark radio buttons, used when auto-generating new data source base colors
\item DSType Palette: One color button per DSType, with a 'Reset to Defaults' action
\item DBContent Palette: One color button per ASTERIX CAT, with a 'Reset to Defaults' action
\item Per-Data-Source Controls:
\begin{itemize}
\item Base color button
\item Four line color buttons (L1 through L4) with individual reset buttons
\item Bulk actions: 'Auto Light All', 'Auto Dark All', 'Reset All'
\end{itemize}
\end{itemize}
\ \\

Each change is stored immediately in the active context. \\

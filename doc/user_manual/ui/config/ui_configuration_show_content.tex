\subsection{Show DBContent}
\label{sec:configure_show_content}
\label{sec:configure_meta_vars}

The 'Configuration $\rightarrow$ DBContent' menu entry opens the 'Show DBContent' dialog, which displays all Meta Variables and DBContent variables for inspection. \\

\begin{figure}[H]
  \centering
  \hspace*{-2.4cm}
    \includegraphics[width=18.8cm,frame]{figures/configuration_show_content.png}
  \caption{Show DBContent}
\end{figure}

On the left side, a tree lists the variables:

\begin{itemize}
\item 'Meta': The Meta Variables
\item One node per DBContent (e.g. 'CAT001', 'CAT062', 'RefTraj'): The variables of the DBContent
\end{itemize}
\ \\

Selecting a variable shows its details on the right side. For a Meta Variable:

\begin{itemize}
\item Name: The name of the Meta Variable
\item Comment: Description, e.g. the DBContents in which the Meta Variable is not defined
\item One row per DBContent: The DBContent variable the Meta Variable points to, empty if not defined
\end{itemize}
\ \\

For a DBContent variable:

\begin{itemize}
\item Name: The variable's name as used inside COMPASS
\item Short Name: Brief name, shown where space is limited (e.g. the Table View header)
\item Comment: Description of the variable's meaning
\item Origin: The ASTERIX data item, the input variables of a calculated variable, the alternatives of a selection, or an internal value (see \nameref{sec:key_concepts}), read only
\item Data Type: Underlying data type (bool, int, float, string, ...)
\item Unit: Physical unit if applicable
\item Representation: Display representation (decimal, hex, octal, ...)
\item DBColumn: Name of the database column
\end{itemize}
\ \\

Editing is gated to \textbf{expert mode}. By default the dialog is read-only and titled 'Show DBContent'. In expert mode, it is titled 'DBContent', the fields can be changed and a Meta Variable can be deleted with the 'Delete' button. Expert mode is enabled with the '--expert\_mode' command-line flag at application startup (see \nameref{sec:command_line}).
